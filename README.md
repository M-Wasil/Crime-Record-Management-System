# Crime Record Management System

## 📌 Overview

The **Crime Record Management System** is a C++ based academic project developed as part of a **Data Structures & Algorithms (DSA)** course. The system is designed to efficiently store, manage, and retrieve criminal records by applying core data structures to a real-world problem scenario.

The project focuses on performance, structured design, and scalability while reinforcing practical DSA concepts beyond theoretical use.

---

## 🎯 Objectives

* To apply Data Structures & Algorithms in a real-world inspired system
* To efficiently manage large sets of criminal records
* To support fast searching, insertion, deletion, and updates
* To maintain organized and modular code structure

---

## ⚙️ Features

* Add new criminal records
* Update existing records
* Delete records
* Search records efficiently
* Indexed data handling for optimized lookups
* Modular and extensible design

---

## 🧠 Data Structures Used

* **AVL Tree** – for balanced and efficient record searching
* **Hashing** – for quick access and indexing
* **Graph** – to represent relationships and connections where applicable
* **Queue** – for sequential processing and task handling
* **Linked List** – for dynamic data storage

---

## 💻 Tech Stack

* **Language:** C++
* **Paradigm:** Object-Oriented Programming (OOP)
